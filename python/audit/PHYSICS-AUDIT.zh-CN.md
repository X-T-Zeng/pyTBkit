| M-07 | 官方 HR.fft 新增轨道位置速度修正的符号与其 exp(+ikR) 约定相反 | 用实空间 v=i[H,r] 独立检验；补丁保留第4输出并改正符号 |

M-07 的检验采用明确的点轨道假设与 hbar=1：
`v_ij(k)=sum_R i*(R+tau_j-tau_i) H_ij(R) exp(ikR)`。
在能量本征基内应为 `dH_nm + i*(E_n-E_m)*tau_nm`。
完整 Wannier 速度/几何还需要位置或偶极矩阵，只有 hr.dat 与中心不能恢复全部信息。
Python 默认几何是系数框架几何；embed_orbitals 明确提供点轨道嵌入和边界 sewing。

## 验证层次

- 解析允许空间：C3/C4/C6、C3v+T 三阶表面模型（5个参数）、BHZ 二阶（7个参数）。
  检查维数、线性张成空间、群闭合、投影幂等，而非只看生成项残差。
- 运行官方教程中实际 BHZ Term 表达式与 Pauli 张量积，比较 Python 的 H(k)、
  能谱和生成空间。没有声称完整 MATLAB 类/符号工具箱在 Octave 下受测。
- 固定官方源码的原始计算与提议补丁分开验证。NCTE 原始式对照指定 eta=0
  并匹配 k_B*T；不能把干净极限的一致性称作所有有限展宽方案已经复现。
- 独立物理判据：Hermitian、简并微扰、规范协变、对易子、Fermi 奇偶性、
  解析能谱、非零 k 空间群 sewing，以及点轨道 Berry/Wilson 位置项。

## 后续以 Python 为主的架构目标

1. 将模型表示、基底/位置连接、单位/归一化、算符与后端分层；杜绝隐含框架切换。
2. 谱与导数作为可复用的局部 batch 数据，避免不同响应重复对角化；不用全局模型缓存。
3. 保留精确构建与数值构建两条路径，误差/秩阈值显式化；生成后给出可复核证书。
4. Numba/NumPy/稀疏/Fortran 先过物理与误差验证，再按真实负载比较性能。
5. 每个新功能有可执行例子、独立判据和适用边界；原公式与独立推导冲突时不盲目照搬。
6. 保留精确符号参数与公式呈现；符号层不得隐式浮点化，也不得用未知假设下的
   “无法证明非零”当成对称性或厄米性已通过。符号主线及待迁移功能见
   [SYMBOLIC.zh-CN.md](../SYMBOLIC.zh-CN.md)。
