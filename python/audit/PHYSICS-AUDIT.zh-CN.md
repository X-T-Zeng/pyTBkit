M-07 的检验采用明确的点轨道假设与 hbar=1：
`v_ij(k)=sum_R i*(R+tau_j-tau_i) H_ij(R) exp(ikR)`。
在能量本征基内应为 `dH_nm + i*(E_n-E_m)*tau_nm`。
完整 Wannier 速度/几何还需要位置或偶极矩阵，只有 hr.dat 与中心不能恢复全部信息。
Python 默认几何是系数框架几何；embed_orbitals 明确提供点轨道嵌入和边界 sewing。

## 接续：角动量CG与有限群重数空间

固定官方源的`Y_l__m.ClebschGordan`六标量调用二向量接口而失败；`Y_l__m.CG`禁止通道
把0写入错误输出变量。原式已分别在Octave复现；独立candidate只修正这两行，按358组
精确角动量系数验证两个入口。小j范围外的稳定性及完整MATLAB类仍未覆盖。

Python补充常量精确/数值的普通有限群CG和对齐副本，不把中央等型投影误称为已经分离副本。
与群对易的H在相应列顺序中是`A_m tensor I_d`，等价副本可混合，整体相位和U(m)规范非唯一。
反幺正/投影表示及Bloch sewing不可直接套该公式。证据与适用边界见
[COUPLING-REVIEW.zh-CN.md](COUPLING-REVIEW.zh-CN.md)。

## 接续：角动量与旋转不变量

main 13a5832的Python原式已复现五个数值边界问题：相对isclose把非半整数j当合法表示，
轴的巨大/极小量级改变旋转，隐藏1e-15剪枝抹掉切线响应，轨道正交检查隐含相对容差，
巨大有限角的矩阵指数产生非有限值。新分支分别以离散2j、缩放归一化、保留振幅、
绝对实正交检查与SU(2) 4pi半角约化修正，验证全部对易式/Casimir/Pauli闭式。

官方原式高j也有独立失效：CG阶乘乘积溢出，Wigner3j的log-gamma交错和仍能产生
违反归一化界的有限错误。本轮保留原始执行证据，没有新增高j MATLAB候选补丁。
Python提供SymPy精确标量CG再数值化的准备路径，不将不稳定Racah和包装成Numba加速。
证据、输入域与范围见[ANGULAR-REVIEW.zh-CN.md](ANGULAR-REVIEW.zh-CN.md)。

## 后续以 Python 为主的架构目标

1. 将模型表示、基底/位置连接、单位/归一化、算符与后端分层；杜绝隐含框架切换。
2. 谱与导数作为可复用的局部 batch 数据，避免不同响应重复对角化；不用全局模型缓存。
3. 保留精确构建与数值构建两条路径，误差/秩阈值显式化；生成后给出可复核证书。
4. Numba/NumPy/稀疏/Fortran 先过物理与误差验证，再按真实负载比较性能。
5. 每个新功能有可执行例子、独立判据和适用边界；原公式与独立推导冲突时不盲目照搬。
6. 保留精确符号参数与公式呈现；符号层不得隐式浮点化，也不得用未知假设下的
   “无法证明非零”当成对称性或厄米性已通过。符号主线及待迁移功能见
   [SYMBOLIC.zh-CN.md](../SYMBOLIC.zh-CN.md)。

## 接续：谱入口的厄米性定义域

原始固定绝对容差会接受小能量非厄米 H 和小归一化非厄米 S，令厄米求解器输出
虚假实谱。本轮以逐矩阵、默认纯相对 Frobenius 判据统一稠密/稀疏检查，并覆盖
广义谱及导数。官方 EIGENCAR_gen 的重叠投影/不定度量路径只做原始表达式级特征验证，
不冒称完整 MATLAB 类已验证或已修复。物理反例、容差兼容边界、Numba 和复现命令见
[HERMITICITY-REVIEW.zh-CN.md](HERMITICITY-REVIEW.zh-CN.md)。

## 接续：非正交 Gram 条件与换基

固定绝对简并阈值会使非简并广义带梯度因能量单位变化而报错；病态 Gram 缺少
可靠性门，舍入后可能已不代表原来的精确模型。新增逐带残差/Gram 误差与条件估计，
默认拒绝超预算基底，不自动删基。官方 Umat 只改 H、不改 S 的原始表达式已有
严格幺正换基反例，尚未形成完整 MATLAB 类补丁。
证明、接口变化和验证边界见 [NONORTHOGONAL-REVIEW.zh-CN.md](NONORTHOGONAL-REVIEW.zh-CN.md)。

## 接续：长度单位、近邻与共同晶格

原始固定近邻长度容差会删掉真实非零键，两个ss轨道的谱从[-1,1]错变为[0,0]；
宽松共享胞比较还会把两个不同Bloch函数合成错误的HR。行列式绝对阈值与直接norm
也使晶胞/Slater–Koster方向依赖长度单位。现以共用相对几何校验、cutoff单位近邻搜索、
稳定方向归一化与有界像分配修正，并按解析谱、独立R枚举、倒格矢双基和多后端验证。
官方get.Gk原始语句另在Octave验证；nn的Å约定只做接口审阅，不冒称完整MATLAB类已验证。
详见 [LATTICE-REVIEW.zh-CN.md](LATTICE-REVIEW.zh-CN.md)。
